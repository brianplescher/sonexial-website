FREQUENTLY ASKED QUESTIONS

Understanding Generative Engine Optimization (GEO)

What is an llms.txt file and why does an author need one?

An /llms.txt file is a standardized markdown roadmap placed in the root directory of your website. It provides LLM crawlers (ChatGPT, Perplexity, Claude) with structured, clean text summarizing your books, series reading order, tropes, and buy links without clutter from scripts or navigation menus.

Why is JSON-LD schema critical for AI search engines?

Schema.org JSON-LD tags (specifically Person and Book schemas) declare unambiguous entities in your code. When a reader asks ChatGPT "Who wrote The Silent Orbit?", schema markup connects your author entity directly to your books and knowledge graph nodes.

What if my site is blocking AI crawlers in robots.txt?

Many default website builders or security plugins block GPTBot, ClaudeBot, or PerplexityBot by default. If blocked, these engines cannot index your website, making your books effectively invisible when readers query AI tools for recommendations.
